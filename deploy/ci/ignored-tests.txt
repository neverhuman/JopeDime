# deploy/ci/ignored-tests.txt — the committed allowlist read by deploy/ci/no-silent-skip.py.
# A test may be absent from a lane's results only if it is listed here. Two kinds of line:
#
#   ignored <binary-id> <test-name> <reason>
#       A #[ignore] test. Either a child fixture that a parent test re-executes with the
#       env variables in the last column (the parent proves it ran: the parent is a normal
#       test and must appear in the junit), or a manual/benchmark test with no CI lane.
#   gated <binary-id> <test-name> <lane> <ENV1,ENV2,...|-> <reason>
#       A test that returns early ("skipping …") when the named env variables are unset.
#       It must run for real in exactly one lane: there, no-silent-skip requires the variables
#       to be set and fails on a skip marker in that test's output; in every other lane its
#       skip marker is allowed.
#
# Binary ids are cargo-nextest's (`<package>` for lib tests, `<package>::<test-file>` for
# integration tests, `<package>::bin/<name>` for binary tests). Keep in sync with
# `cargo nextest list -P main --workspace --message-format json` (docs/ci.md, "No silent skip").
