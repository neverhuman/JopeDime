# deploy/ci/repo-layout-allow.txt: the reviewed exceptions to `jope-records repo-layout`
# (hygiene lane, deploy/ci/check.sh). One entry per line: <kind> <path> [<value>] -- <reason>
#
#   root-md <file>             a Markdown file allowed at the repository root
#   log <file>                 a tracked .log, .err or .stderr file
#   dir-package <dir> <name>   a workspace member whose directory differs from its package name
#   temp-dir <file> <count>    test code in <file> may use the process-wide temp directory at
#                              most <count> times (production callers are out of scope)
#
# The list only shrinks: an entry for an untracked path, a count above the actual count, or an
# entry that matches nothing fails with "lower or remove this entry". A new entry is a reviewed
# diff with its reason. dup-package (two Cargo.toml files declaring one package name),
# bad-manifest (a tracked Cargo.toml not readable as TOML 1.0: not UTF-8, not TOML 1.0, or a
# [package] without a non-empty string name; manifests are read as TOML 1.0, so every TOML 1.0
# spelling of a name counts, and TOML 1.1-only syntax that Cargo accepts must be rewritten) and
# bad-path (a tracked path that is not UTF-8, which no other rule can check) have no exceptions.
