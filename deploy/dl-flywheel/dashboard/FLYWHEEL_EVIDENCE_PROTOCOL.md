# Flywheel evidence and game-data protocol

Data→licensed frozen KumoSmall2051→model-produced typed GP→native execution and Rust parity→typed genetic evolution→versioned measured game library→numerical train targets→immutable closed-epoch admission→committed learner update→same-context evaluation→next train feedback.

Raw, encoded, emitted, scored, published, admitted and consumed remain separate. Each context binds parent/source/transform/RNG/target/split roles, byte hash and versioned objects. Descendants inherit parent roles, batches have at most one context per parent, and exhaustive shuffled epochs do not repeat whole membership. Validation results never become optimizer targets. Reserved26D tuning and27D confirmation remain additional partitions, separate from original fixed panels.

The older PolicyLM uses supervised imitation/ranking and frozen6640trie. Dense supervised feedback, CE teacher/trie promotion, shadow actor and live on-policy RL have separate qualification. For dense RLOO, detached per-item importance weighting differs from joint-group weighting for a maximum objective; raw iid/no-anchor applies only to alpha1 and generalized alpha needs anchor^(alpha-1), exact behavior and support. Dashboard arrows describe interfaces, not admitted RL.

Typed GP evolution starts from valid model structures, uses the same measured context/evaluator/objective and equal budgets, and records parent custody. Every numeric result requires native/Rust1e-9 parity; parity_unqualified is nonnumeric/noq/no automatic retry. Infrastructure failures and optimizer-unknown outcomes are separate. An emitted proposal, cache hit or library score is not a learned update or generalization result.

A repeatable closed-epoch transfer preserves full model/AdamW/CPU+CUDA RNG, exact ordered refs, roles, fingerprints, objective/normalizer, checkpoint/control/planner/outbox and cumulative ACK/membership joins. True-next-update parity precedes the once-only R14 LR event. Terminal verification precedes clean success; missing/stale/late/failure/intent-only verification cannot resume. Actual first new-target batch exposure and a joined physical changed parameter are required before showing feedback-to-learning completion.

Old plays retain value when program/data/split/evaluator/objective/normalizer identities match. A better model does not rewrite old scores. Separate raw RMSE, same-split baseline and normalized objective; never conflate a new CatBoost-relative objective with historical mean-baseline feedback. Completed keys are cache-only, missing artifacts do not authorize reexecution, canonical aliases/global attempt/unknown guards apply across original and continuation outboxes.

S3 management measures bytes, request count, wall/CPU timing and prices; forecasts are not bills or grants. No deletion until exactVersionID/memberSHA archive, consumed membership, archive-aware tuple/tombstone resolver and dryreport qualify. Pre-v2 data is untouched. Shared-CAS multiowner resolution is held. GlacierIR short retention and tiny objects are unsuitable because90day/128KB minimum billing applies. Report comparisons under same contexts and equal budgets, include failures and cost, and measure uplift after actual target consumption. No wins/Elo/generalization or causal improvement claim follows from publisher health, source fixtures or utilization.
