## Measurement limits

The fixed eight-program panel provides initial measured label coverage. It is not a model-proposed program stream and does not by itself demonstrate model lift. The inherited timed worker records elapsed wall time and RSS; exact CPU user/system time, aggregate child CPU time and complete compilation/data-fetch/native-execution/publication phase timing are not yet recorded by that wrapper. Existing detailed event timestamps must not be presented as those missing measurements. Current host idleness is not a resource authorization: actual reservations and current headroom remain launch gates.

The underlying GPU model remains unchanged. Any reward or distillation change needs separate executed-score qualification and review; this fixed-panel scoring package provides neither approval nor model-quality evidence for that change.
