# Generated variant GP evaluation from the model outbox

This bridge connects **actual PolicyLM train/validation emissions** for admitted real-data variants to the qualified local Lambda evaluator, emitted Rust execution and version-verified S3 program library. It is separate from the eight fixed curated controls. A proposal is not a score. Publication is not optimizer admission or evidence of a win.

## Durable execution path

1. Hold one nonblocking kernel lock beside the active outbox for the entire packet. Select only fresh recorded `flywheel_variant` emissions; leave native-context and historical leased/unknown rows untouched.
2. Bind original model ancestry, batch membership, phase, exact descriptor and raw GP bytes. Freshly replay RegisteredInputs and inherited role. Canonicalize with the pinned native binary; derive the exact Context/program evaluation key.
3. Refuse keys with prior failed, running, unreconciled or partially published attempts, including canonical aliases from different batches/phases. A historical completed key is **cache-only**: missing or unverifiable publication becomes nonnumeric unknown custody, never a new test.
4. Durably observe the actual model emission. Confirm an authoritative S3 miss, or verify the cached wrapper and all seven artifacts. Authentication/network errors are unknown, never absence.
5. For a genuinely new key, enqueue the qualified evaluate→publish dependency pair. Bind observer/worker to the same queue, input authority and store. Refuse unrelated or unresolved queue jobs before worker execution.
6. Execute the native local Lambda two-fold fit, emit Rust, compile and run both folds. Preserve fit-only minmax scaling and fixed `1e-9 * max(1, abs(reference))` prediction parity. Reconstruct actual RMSE and canonical score rows. Any failure has no numeric score.
7. Publish input, program, evaluation, Rust source, executable, parity provenance and score rows create-only under the established versioned library prefix. Publish the wrapper last; verify exact versions, hashes, sizes, Context and seven-artifact semantic closure before resolving the model outbox.

Successful results stay research measurements with `optimizer_reward_allowed=false`. This adapter does not change CE teachers, HWM winners, CatBoost/mean-baseline objective identities, corpus readiness, validation roles, Elo or opponent games. Separate reviewed admission is necessary before any generated measurement affects gradients.
