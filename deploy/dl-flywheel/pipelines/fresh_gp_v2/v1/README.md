## Why this packet is stopped

There is no fabricated substitute for the following missing integration work:

1. A read-only cold capture/verification adapter must produce the **full18
   legacy variant queues and original/continuation outbox** sources. Capture
   all rows, exact original context descriptors and canonical programs, verify
   queue/event identities, physical closure and source pins. The local
   `History` consumer has fixtures, but no actual host captures in this packet.
   Original-native outbox aliases require exact typed contexts; unresolved
   aliases deliberately fail, rather than being treated as irrelevant.
2. A reviewed cross-host whole-context ownership producer/lease is still
   required. It must check historical launch controllers inactive, current
   legacy units physically closed, active xbabe2 scorer source-kind and actual
   descriptor disjointness, and all other variant writers. Its certificate
   schema is validated here, **but the certificate producer is not implemented
   or qualified here**. Booleans manually copied into JSON are not proof.
   Do not copy or open the active xbabe2 registry on xbabe3.
3. Exact128 raw/Kumo per-variant S3 receipt bodies, parent1068 registry/source
   replicas and full native closure must be current-role checked, exact-version
   read back and deterministic-replay qualified. Derive native context IDs
   through the pinned canonicalizer, not from variant IDs or metadata alone.
   Freeze source proofs and actual Kumo runtime/manifest/publisher pins into
   each registry row. Current local tests use explicit synthetic receipts;
   they are not evidence of real S3 revalidation.
4. A new reviewed scheduler/CLI must wire the unchanged ordinary<=128-eval
   GP worker path, context reservations, guard, source import checks, cgroup
   observation, exact measurement completion callback, failure custody and
   status/timing collection. The historical scheduling/custody modules are
   copied under `provenance` for reference **and must not be launched unchanged**.
   `Attempts.complete` requires an exact-result verification callback; it is
   not yet wired into an operational campaign CLI. Cached measurements need a
   distinct final count; unknown holds must never be recategorized as not started.
5. Final source pins, independent review and actual no-fit/no-PUT CPU preflight
   must pass before root freezes the one-use window. This task adds no SSH,
   systemd launcher, S3 writer or automatic retry path.
