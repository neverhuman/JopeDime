# Generated result production callbacks, v1 — source-only proposal

This package verifies already published or cached **training-phase variant** results. It never evaluates a GP, writes S3 or SQLite, creates a broker, admits optimizer targets, updates a checkpoint, modifies a normalizer, or promotes generated programs to CE teachers. The existing exporter and its 28 fixtures remain unchanged.

## Current boundary and completion criteria

The concrete CLI performs selected-result qualification only: one to four successful training rows from a finite, hash-pinned physical observation; the complete adopted128 descriptor roster and current parent authorities are checked, but only selected contexts receive `RegisteredInputs.describe` replay and fresh exact-version dataset reads. Seven result artifacts are verified by the original `program_gate.verified_measurement` and original `score_join` using the exact native canonicalizer. Results explicitly report `full_cutoff_verified=false`, `reference_export_completed=false`, `numeric_targets_materialized=false`, `optimizer_admission=false`, and zero GP/PUT/DB/optimizer operations.

A successful selected qualification is **not** proof that the observed outbox event/ACK chain or optimizer commit is valid. The observed row's content hash, deterministic emission identity, phase/batch membership, descriptor, canonical result key, exact wrapper and all seven artifacts are checked. Root's dated candidate observation is a selection input, not an invented full cutoff. Unknown, failed, unmeasured and validation observations cannot become selected targets.

The current c961 predecessor contains a seven-field `encoder_publication` reference, whereas its admitted descriptor uses the five identity fields. `bindings.publication_identity` accepts the five fields plus the two known custody annotations, validates the annotations, compares identity only, and never rewrites the source extension. The actual-shape fixture preserves this evidence. **The frozen exporter rejects those original annotated task refs. Full actual export is therefore HOLD pending a separate cold exporter compatibility successor.** The `authority` callback also refuses that actual predecessor; it will not pretend the current exporter can consume it.

## Callback contract and authority reuse

Callbacks are top-level functions with no defaults or closures, suitable for `CheckedCallback`. They use an internally constructed frozen Runtime holder configured once from reviewed bytes. No caller can pass a client, canonicalizer or role function to `configure`. This trusted reviewed Python code is not a sandbox against arbitrary in-process monkeypatching. External tests replace transport/subprocess boundaries only; no synthetic callback is installed by production code.

`verify` uses an exact-reference seven-body store, never a bare callback success. It checks native source/build provenance, context and canonical program, then uses the original gate to recompute fold RMSE and validate the native canonical score rows. It produces measurement proof only; q_opt/q_grid, opposite-fold mean baselines and rank targets remain the unchanged later labels/compose job. Missing terms are never fabricated, CE remains false, original normalizer/fit6857 and support-mask objective are bound.

Full authority setup, if separately enabled after compatibility repair, must replay every128 context first; thereafter callback checks can re-read the exact replayed source pins and current physical authorities rather than rerun deterministic transforms for every callback. Changed input, role, source, canonicalizer or normalizer bytes refuse. The current selected CLI cannot obtain full authority from a partial replay or request echo.

## Timing and bounds

GET attempts are charged before dispatch; actual body bytes and attempted bytes are distinct. No response error or absence is cached. Header/body/whole-GET spans and native canonicalization record UTC and monotonic start/end nanoseconds, own CPU user/system and child CPU deltas. Nested spans are explicitly not additive; CUDA time is null. Native modes are exactly `--canonical-json`/`--canonical-program`, stdout≤2MiB+newline, stderr≤64KiB, each call≤5s and within the unchanged work deadline; owned process groups are cleaned on all outcomes. GET bodies are streamed in≤64KiB chunks and closed even on wrong headers. First selected mode≤64GET/128MiB/4rows; individual seven-body caps are unchanged. External service deadline remains necessary for OS/SDK blocking beyond Python's control.
