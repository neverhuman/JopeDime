# Strict legacy publication reference compatibility

This additive cold exporter accepts the actual prepared c961 predecessor publication receipts: five exact identity fields, optionally the complete known two-field create-only annotation envelope. It preserves every original task field, annotation, and ordered program-result prefix. It compares normalized admitted descriptors by exact bucket/key/VersionId/SHA/bytes identity. All result references, artifact reads, pending/refused/validation handling, complete cutoff census, authority and objective/normalizer/license checks remain unchanged from frozen v1.

Unknown fields, partial annotations, unknown/failed/unverified publication annotations and any exact-identity mismatch fail closed. This does not make a new source schema a proof of cloud verification. Reviewed production callbacks still must verify actual byte closure and current physical authority.

This package adds eight new synthetic fixtures; it imports frozen fixture helpers without collecting or rerunning old test methods. The frozen v1 source and its 28 completed fixtures stay byte exact. A test deliberately confirms v1 still rejects the actual legacy envelope.

No live cutoff/export, numerical target, teacher promotion, optimizer admission, GP execution, S3 write or RL is performed by this source packet. Full current outbox backup/index and memory/time qualification remain separate. Production use requires cold reviewed runtime/config/dependency closure; never hotpatch active modules.
