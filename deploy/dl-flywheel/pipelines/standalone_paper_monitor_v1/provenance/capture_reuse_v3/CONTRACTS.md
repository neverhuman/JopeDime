`ExternalSeal(physical_pin_json,generation,graph_sha256,acceptance_head_sha256,policy_sha256)` is an OPERATOR trust argument, not request data. Physical pin exact fields are path/sha256/bytes/device/inode/mtime_ns/uid/mode/nlink/file_type. Root read requires immutable regular single-link0400/0444, declared UID and exact same-FD body. RootSeal is canonical <=1 MiB JSON.

RootSeal keys: schema=`codex.monitor-capture-reuse-root-seal/v1`,generation,graph={sha256,bytes},acceptance_head,policy,current,evidence,producer_source,producer_review,root_commitment. Last three are exact evidence content pins. `policy` must equal package.reuse.POLICY; it commits unchanged caps/fresh guard categories, historical freshness wording and fixed read/body/retention/transport limits. `evidence` is the exact set mapping content SHA to {sha256,bytes}; every declared raw body must be supplied and hashed, with no unknown extras.

`current` keys: namespace,root,source_manifest_sha256,config_sha256,clock,snapshot_path,guards,inventory_sha256. Paired clock schema is exact original five fields; current starts no earlier than the immediate predecessor's typed terminal capture. `guards` maps all seven existing categories current_source/current_units_cgroups/current_resource_roster/current_device_policy/current_foreign_boundaries/current_activation_chain/current_clock to exact evidence pins. Authenticating those bytes is not itself re-performing their operational semantics or a fresh system observation.

Accepted graph schema is unchanged `codex.monitor-accepted-custody-graph/v1`: generation_index,namespaces,acceptance_head. Namespace exact keys: id,root,source_manifest_sha256,config_sha256,clock,status,members,member_manifest_sha256,acceptance,window_state. Members: relative_path,role,original,custody. Original is six-field physical descriptor; custody is ten-field immutable descriptor with matching bytes/SHA and disjoint path/inode. Roles and statuses are inherited unchanged from exact vendor schema; no aliasing, overlap, removal, source/config loss, failed/unknown flattening or original-clock reset. Source inventory digest commits all role=source rows. Full graph SHA/head and exact next generation are externally anchored.

Each new typed acceptance has schema=`codex.monitor-capture-reuse-acceptance/v1`,namespace,member_manifest_sha256,source_manifest_sha256,config_sha256,clock_sha256,status,previous_acceptance_sha256,capture,verifier_source,window_state,independent_review,source_inventory_sha256,terminal_capture. capture/verifier_source/independent_review are exact raw metadata evidence content pins. `terminal_capture` is null for all non-normal statuses. For normal_closed it has captured_unix,completed_monotonic_ns,boot_id,fsync_receipt,physical_closure_receipt,event_bytes_pin,result_pin. Clock bounds, raw event/result membership and source/inventory commitments must join. This NEW certificate is not an existing legacy receipt. A reviewed producer must authenticate exact original receipts, not manufacture booleans or reinterpret absent fsync as observed.
