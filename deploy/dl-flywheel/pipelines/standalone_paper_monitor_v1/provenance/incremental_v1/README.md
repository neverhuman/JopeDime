# Bounded pure custody foundations — source only

This is a new local source packet, not a monitor successor or launchable engine. It implements closed pure authority, accepted-history, pending-extension and complete normal-phase contracts. No production module, remote body reader, systemd operation, collector, S3, GP, optimizer, callback loader or scientific dependency is imported. No frozen monitor source was edited. Canonical repository/source integration remains separately owned.

The changed freshness claim is precise: exact historical captured bytes can be authenticated under an independently committed root authority and acceptance chain. This does **not** re-observe old remote paths or claim old remote freshness. Every historical namespace, member, role, original physical descriptor, old clock, failure/unknown/held state, and acceptance link stays named. The initial implementation remains conservative: **all historical body witnesses are still required and rehashed on every invocation**. It is not certificate-only reuse and does not solve indefinite growth. A namespace that was held source-only, or failed before a window existed, explicitly has `window_state=not_created`, null config and null clock; it never gets a fabricated lifetime.

## APIs and trust boundary

- `authority.verify_authority(wire, ExternalAnchor, observed_before, observed_after)` requires an independently committed authority-file SHA/size/physical identity, exact next generation, predecessor graph/head and policy SHA. Before/after identities must equal the anchor. Fixed limits, .25 CPU/128 MiB/swap0/Nice19/Tasks24/noRestart/metadata-only GPU policy, five foreign-boundary commitment and all seven current guard categories are bound. No `approved=True` input exists. The pure library **cannot establish where an ExternalAnchor or metadata observations came from**; a future reviewed same-FD reader/operator must authenticate the external root seal independently of the candidate. The verified object token prevents accidentally replacing fields while carrying an old proof; it is not a sandbox against hostile Python code in the same interpreter.
- `custody_manifest.verify_accepted_history(graph_wire, acceptance_wires, witnesses, authority)` validates the entire externally pinned graph, complete chained acceptance receipts, source/config/clock/status/member joins, namespace/path/inode nonaliasing, and every exact captured byte against immutable local custody before/after metadata. It does not re-execute the old verifier or inspect the original remote file. The root-anchored acceptance chain attests the *original* acceptance decision; this library does not recreate independent ownership from names or receipt flags.
- `custody_manifest.verify_candidate(candidate_wire, history, fresh_witnesses, authority, accounting)` verifies an exact old prefix plus one source/config/clock-bound namespace. It preserves old bytes and refuses to extend the normal path from an immediate failed/unknown/held predecessor. Earlier failed/unknown/held entries remain. New state is only `pending_verification`, with no acceptance ref. It returns no runtime/admission permission.
- `phase_verifier.verify_normal_phase(config_wire, event_wire, result_wire, final_snapshot_wire, PhaseBinding, phase)` replays the original four-state canonical event protocol, exact config and both event clocks, prior accepted/observed prefixes, full result/custody joins, zero scientific counters and exact copied final snapshot/source/config/attempt. It accepts qualification or clean near-end live closure, never a failure-prefix bypass. Actual `legacy_history_readonly` is null or an exact pinned `{path,sha256,head,bytes}` descriptor; a boolean is refused. Tightened JSON/body/attempt/hash checks are explicit. The inherited strict paired-duration tolerance remains <10 microseconds. The decimal snapshot cap is 7,500,000 B. This proof does **not** establish process exit, current physical closure, current foreign/device/resource guards, stage/dispatch/parent-result joins, or actual terminal monotonic time (the historical result has no such field).

Inputs are immutable bytes plus closed structured values, not generic verification callbacks. All claimed current read counts and same-FD observations still require a independently qualified IO producer. These functions check binding and bounds, not an echo producer's honesty. Historical acceptance schemas here are new closed contracts: no adapter for actual V8–V14 captured metadata is supplied or qualified.

## Bounds, accounting and remaining HOLDs

Per body 8 MiB; event 512 KiB; final snapshot 7,500,000 B; canonical metadata document 1 MiB; 32 MiB fresh read total; **32 MiB cumulative decoded witness bytes (old plus new)**; 48 MiB serialized transport. Complete declared witness totals are checked before consuming witness iterators. Old reused bytes, new fresh bytes, decoded bytes and transport counters stay separate. Transport is checked against a minimum payload footprint, not claimed fully measured by this pure source. Same-FD read details, event reread charges, manager/pseudo-file charges, durable partial records and full serialization accounting remain the future IO producer's responsibility. No larger budget, dropping old members, stat-only acceptance, read retry, old clock reset or new execution is enabled.

The source has no retained-body streaming engine and makes no RSS claim. Inputs may already occupy memory; rejecting an iterable before consuming it is not proof that an external caller did not preallocate it. No actual 128 MiB cgroup qualification occurred. A valid current pending manifest is **not** normal terminal acceptance, a monitor launch, a numerical target or optimizer admission.

Separate next packet, requiring its own closed policy and independent disposition: an externally anchored accepted-custody certificate graph may reference exact historical bodies as verified at original acceptance, without loading every body now. It must retain full identities/states/old clocks, pin the original independent acceptance chain, reject rollback/substitution, and rehash any body on later actual use. Missing/corrupt referenced custody produces HOLD, no science retry. New deltas and every current guard remain fresh. This proposal has not implemented that policy; finite body growth remains HOLD when the conservative bound is exceeded.
