# M3 frozen S1 evaluator repair

The version-2 surrogate reused the generic `NativeModel` scaler. That scaler clips validation features to `[0,1]`, collapses constant columns to zero, and floors target spans at `1e-12`. The frozen R0 `s1main::one_fit` instead fits min/max on each training fold, divides constant spans by one, preserves every positive target span, and applies the affine transform without clipping. A validation row outside its training range must remain outside `[0,1]`.

Keep the repair inside the existing version-2 surrogate: reproduce its frozen finite-input scaler around the same current `feat_math` fit/predict APIs and retain the original baseline summation order. The frozen S1 reader refuses nonfinite feature values; this path does the same. Generic version-1 evaluation, missing-value imputation, private refit artifacts, finalization/export, objective selection and wire/bundle/file schemas retain their existing contracts. Rejected alternative: changing generic `NativeModel` would also alter persisted predictor and export semantics unrelated to this parity repair.

An end-to-end data-free worker regression uses two disjoint feature ranges and an independently calculated frozen S1 fitness. It fails on unchanged production code. Five approved real TRAIN records, including two gate flips, exactly match their R0 fitness after restoring frozen preprocessing in an independent diagnostic linked against the current compiled `feat_math`. The fixed product callback must then replay all 1,024 original full-TRAIN cases with unchanged `1e-9` relative tolerance and gate decisions; results remain source-pinned evidence, not signed-candidate qualification.
