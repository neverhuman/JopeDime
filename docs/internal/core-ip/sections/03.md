# Encoders and Hyperion

The accepted context combines three products with distinct semantics. A tensor width is not a type: a 512-value cell surface, pooled dataset signature and target representation are not interchangeable. The CUDA loader added for this study requires CUDA devices for Hyperion, Foundation and Target and refuses a CPU device before opening assets.

## Product and shape contracts

| Product | Semantic object | Relevant shape |
|---|---|---|
| Hyperion cell surface | Per-cell transform/feature surface | Depends on sweep/version configuration; not a context ABI |
| Hyperion V7 row embedding | One representation per feature row | 128 per row on this accepted path |
| Dataset signature | Four summaries per embedding coordinate | 4 × 128 = 512 |
| Foundation raw context | Target-conditioned table summary | 2,048 before frozen projection |
| Foundation projected context | Frozen transformed summary | 1,024 |
| Target context | Frozen target-window encoding | 512 |
| Teaching/proposal context | Concatenated normalized blocks | 2,048 |

## Pinned encoder architecture

The accepted-path Hyperion manifest is named `hyperion_v5_arm_b.manifest.json`, but declares version **v7**, width **128**, **4 attention heads**, **4 blocks**, embedding width **128**, four bands, patch sizes2–16, quantile bounds1/99, quantization scale3 and padding byte128. Its window list is4,7,11,15 and recorded step is0. The filename and recorded step do not prove a training lineage. These are refreshed asset fields, retained with all weight/configuration hashes in `encoder-assets.json`; the generic v7 source comment describing512-wide,12-block geometry is not this asset's geometry.

The implementation embeds each patch cell's value and validity mask, adds a scale embedding, and pools row and column states. Each dual-axis block performs row-to-column and column-to-row attention with validity masks, then adds its feed-forward result and normalizes. A global-statistics head combines the row/column summaries and normalized patch scale; a band-gated head combines shared coordinates with the active scale band and zeros inactive bands. The embedding-only route omits the confidence head. Patch embeddings are scattered back through inverse row/column permutations before row aggregation. Sources: `crates/hyperion/src/hyperion_v7/model.rs`, `crates/hyperion/src/hyperion_v7/sweep/driver.rs`, `crates/hyperion/src/hyperion_v7/config.rs`.

A sweep's first permutation is the identity; later permutations are seeded. Generic sweep defaults specify30 sweeps, while the accepted context producer explicitly selects3. The publication uses the producer's settings, not the library default. Cell maps, patch embeddings and final128-coordinate row embeddings are separate intermediate products.

Starlight is the Foundation component's source name. Its regression model yields512-coordinate query hidden states, pooled by mean, population standard deviation and10th/90th percentiles into2048 values. The accepted producer chooses at most768 context rows and256 query rows. The internal model constants distinguish128-dimensional feature embeddings from the512-dimensional in-context lane with8 heads; these must not be confused with the separate512-wide program generator. Sources: `crates/jope-encoders/src/foundation.rs`, `crates/jope-encoders/src/model.rs`.

## TrainFitted and historical joint processing

`OrigV2PairSemantics::JointCompatibility` reproduces a historical feature-level transductive experiment. `TrainFitted` fits the ranking state on training data and applies the frozen state to subsequent rows. This distinction in `crates/hyperion/src/hyperion/orig_v2.rs` does not, by itself, prove whole-pipeline isolation: an upstream scaler, Foundation label input, learned checkpoint or downstream adaptive choice can still violate the intended boundary.

### Rank transforms and inference scope

A training-fitted empirical rank map can be described by the empirical cumulative distribution of the training values. New values are located against the frozen training reference. Joint ranking instead changes the reference when test values change. A useful noninterference test mutates the forbidden rows and asserts that fitting-side ranks, scaler state, encoder output and context digests remain unchanged.

#### Counterfactual test design

Keep original fitting membership and labels constant. Replace held labels, permute held features, and add extreme held-only categories. Run the entire permitted producer closure again. A claimed training-only summary must have the same bytes or satisfy a preregistered numerical equivalence rule. Merely testing the final 2,048-vector width would miss a same-width component substitution.

## Encodings and the proposal context

### Regression context production

#### Original data and preprocessing

The context input binds prepared-data hash, exact training-content hash, ordered fitting-row hash, cut identity and preprocessing hash. It requires at least eight training rows and a nonempty declared feature schema. Numeric versus categorical kinds come from the schema rather than guesses based on strings. Numeric nulls are imputed using training-only medians, with a zero fallback for an entirely missing column; the recorded training transform contains its fitted location/scale. For categories, every present string is a value, including empty text or strings spelling `NA` or `null`. Only an absent value is missing. Original target strings remain separately authenticated before numerical regression parsing.

This context preprocessing is for the proposal encoder. It does not authorize discarding the original schema or replacing a fitted predictor's own training-only preprocessing. Source: `crates/jope-policy/src/context_producer/input.rs:84`.

#### Component dimensions and assembly

The current CPU producer uses three components with fixed pretrained assets and fixed transforms:

| Component | Production | Raw output | Contribution to policy context |
|---|---|---:|---:|
| Hyperion | Training feature columns only (no label), quantized from fitted quantile bounds; three embedding sweeps, scales 4/7/11/15, batch 1024, internal setting `target_chunks_per_sweep=1` (a chunking setting, not the label) | 128 values per row | Mean, population standard deviation, 10th and 90th percentile per coordinate: 512 |
| Foundation | Feature columns plus the training targets as in-context labels, prepared with the native deterministic recipe; target normalization computed in f64 after the native f32 cast | 2048 | Frozen mean-centering, learned 2048→1024 projection, then frozen normalization: 1024 |
| Target | Training targets, already standardized in preparation, then min–max rescaled to [0,1] by the training minimum and maximum (span 1 when constant); two frozen native target windows with seed 17 | 512 | Frozen normalization: 512 |

Assembly concatenates normalized Hyperion512 + projected Foundation1024 + Target512 and clips the full 2048-vector to [-32,32]. Only the Hyperion block is label-free: Foundation is conditioned on the training targets, so the first 1,536 values, which the policy configuration still calls `dataset_dim`, include target-conditioned values. It checks all component dimensions and finite values. The source explicitly checks that the Hyperion row width is 128; confusing row width with pooled512 changes the model input meaning. Sources: `crates/jope-policy/src/context_producer.rs:188`, `:278`, `:356`, `:399`, `:422`.

The deterministic foundation preparation selects at most 768 context rows and 256 query rows before `encode_standardized`; that encoder adds no further cap. Hyperion receives every supplied training row and feature column, with no row/column subsampling in this producer. The serialized input is capped at 128 MiB and every context job remains subject to the fixed 30-second worker deadline. On the eight final reference jobs at source `68f56404`, Hyperion-stage elapsed time ranged from 6.143 to 14.287 seconds; whole-job wall time ranged from 11.731 to 20.755 seconds. These small-case measurements do not establish coverage for wider or larger cuts. A timeout leaves the context unavailable; it does not permit a new deadline or silent subsampling.

The frozen numerical qualification contract is unchanged, but the implementation includes both execution and numerical corrections. Hyperion uses an embeddings-only sweep that skips the unused confidence head. Foundation uses the separate `encode_standardized` path: train-side feature moments accumulate in f64 before the retained f32 transform, and p10/p90 use Torch 2.7 FP32 rank and stable-lerp arithmetic. Ordinary `encode` retains its legacy feature-moment and percentile arithmetic. The standardized route consumes all rows supplied by the preceding deterministic foundation preparation without additional caps. Cached-decoder fixtures separately check small random-model operations/full-prefix agreement within 1e-4, row/padding behavior and sampling-token/RNG agreement. They do not establish that the Candle CPU policy port matches the trained tch forward pass: the source states that logits and rewards from the port are unverified until reference fixtures exist (`crates/jope-policy/src/lib.rs:84-92`). Historical native tch-to-Candle CUDA policy parity remains unestablished. The historical manual had no compiled CUDA proof; the new timing study is recorded in chapter 10 (`lib.rs:93-95`). Sources: `crates/jope-policy/src/context_producer.rs:238`; `crates/jope-encoders/src/foundation.rs:345`; `crates/jope-encoders/src/foundation/support.rs:123`; `crates/jope-encoders/src/model/tensor_ops.rs:114`; `crates/jope-policy/src/model/cached.rs:270`; `crates/jope-policy/src/decode.rs:485`.

#### Qualification and admission

The CPU regression encoder has a stronger boundary than “the vector has 2048 values.” Eight fixed native-reference cases span two families and cuts 0–3. Qualification checks finite FP32 component and final-context values with maximum absolute difference at most 0.0003, exact asset/source/program identities, and actual bounded executions. Consumption binds those eight jobs plus the actual dataset context job: nine independently authenticated process proofs. The reference registry/index and transform hashes are pinned in source.

The eight retained reference outputs at source `68f56404` have final-context maximum absolute differences from 5.3644180e-5 to 2.8765202e-4. The worst case is `cardata-blackmore`, dataset `55e9dfc7a86361d7`, cut 0: 95.884% of the unchanged 3e-4 tolerance. Across all eight cases, maximum component differences are 4.127622e-6 for Hyperion, 2.908707e-5 for foundation and 3.911555e-7 for target. The frozen projection and projected-scale division can amplify small component differences in the assembled vector. Coverage is limited to two numeric meta-train families: blackmore, 629–630 training rows with 4 features, and `cardata-ces11`, 800 rows with 8 features, each at cuts 0–3. Changes to arithmetic, libraries, build/ISA flags or summation order require requalification; this gate is not evidence for wide or category-heavy contexts. Never relax its tolerance to make a build pass.

`VerifiedCpuContext` has private fields and can only be constructed by the verification path outside explicit test support. A syntactically valid JSON vector cannot create admission authority. Sources: `crates/jope-policy/src/context_producer/admission.rs:4`, `:115`, `:234`, `:297`; `crates/jope-pipeline/src/cpu_context_bridge.rs`.

### Experimental classification context

Current source contains the pure class-partition context representation. The pending training overlay adds the bounded feature producer, process admission and operational proposal wiring. Classification does not parse class names as numbers or reuse the regression target encoder by ordinal coding.

The feature blocks remain Hyperion512 and projected Foundation1024. The pending producer explicitly conditions the foundation path on neutral zero targets and labels this an experimental feature-only probe. Each class gets a centroid over the 128-dimensional training row encodings. The target block contains, per coordinate, the mean, standard deviation, minimum and maximum across class centroids, totaling 512. The centroids are unweighted, so class frequencies never enter the block. Classes are visited in first-row order, so a bijective renaming preserves even floating-point summation order. Original labels still appear in authenticated input identity, even though their spelling cannot influence numerical pooling.

The resulting lineage is `asm.experimental-class-partition-pool/v1`; `policy_compatible` is false. The false marker means it cannot enter the accepted regression policy loader. A declared binary input must have exactly two classes; multiclass requires at least three, and the fitting data must contain the declared classes. Missing classes are an explicit refusal. Sources: `crates/jope-pipeline/src/search_context.rs:278`; pending `crates/jope-policy/src/context_producer/classification.rs:1`.

At source `68f56404`, classification has no neural arm: planning records the accepted regression-only policy as unavailable for binary/multiclass data. The available `asm.generic` classification sampler uses `logit_ridge` for binary or `multiclass_ridge` for multiclass, with l2 in [1e-4, 10], preceded by no transform, `standardize`, `winsor_clip`, or both. Advanced-v3 mutation/crossover preserve that head family and allow at most 4 transforms. A classification ASM result at this source would therefore be a ridge-head transform search; the pending experimental neural consumer is a separate capability.

## Detailed calculation: the 2,048-float context

The CPU producer builds the context from the fitting rows only (`crates/jope-policy/src/context_producer/input.rs:84-217`):

- numeric columns get training-median imputation and a population z-score;
- categories are indexed;
- the target is z-scored.

It then assembles three blocks. `context_producer.rs:189-271` builds the components, `:423-445` pools Hyperion, and `:357-421` standardizes, projects and assembles.

- **Hyperion 512.**
    - Features only, with no labels.
    - Each column is quantile-bounded and quantized.
    - A V7 sweep produces 128 values per row.
    - The rows are pooled per coordinate as mean, standard deviation, 10th and 90th percentile: 4 × 128.
    - Then `h = (hyp − μ_h)/σ_h`.
- **Foundation 1024.**
    - Features plus the training targets as in-context labels, so this block is **not** label-free.
    - It is 2,048 raw values.
    - It is projected with a frozen 1024×2048 matrix: `z = ((f − μ_f)·Pᵀ − μ_p)/σ_p`.
- **Target 512.**
    - Training targets min–max scaled to [0, 1].
    - Two frozen target windows with seed 17.
    - Then `t = (tgt − μ_t)/σ_t`.

The vector is `concat[h, z, t]`, clipped to ±32 (`context_producer.rs:416`). The recipe identity ends in `frozen-512+1024+512-clip32/v1`; the full string is at `context_producer.rs:127`. The policy configuration still names the first 1,536 values `dataset_dim` and the last 512 `target_dim` (`crates/jope-policy/src/config.rs:39-55`).
