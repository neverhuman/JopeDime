## Glossary

| Term | Meaning in this publication |
|---|---|
| Admission | A verified decision that a particular artifact may enter a particular consumer |
| Assembly | Frozen normalization, projection, concatenation and clipping of context components |
| Candidate | One identified executable recipe in a search arm |
| Checkpoint | Model plus required state/identity; optimizer resume requires more than weights |
| Context | The 2,048-dimensional conditional input for this accepted policy |
| Corpus | A content-addressed collection of teaching records; not necessarily sampled exposure |
| Cut | A frozen development partition assignment |
| Fitted predictor | Learned preprocessing and model parameters bound to the training data |
| GP | Genetic programming; not the Gaussian-process regression head |
| HWM | Best retained comparable event under the full comparison identity |
| OOF | Out-of-fold predictions within the declared training-side selection closure |
| Promotion | An explicit selection of a model/artifact for serving |
| Recipe | An algorithm description that still needs fitting |
| Sealed | Outside the learning/search input closure; access must remain separately governed |
| Warm request | Models resident; encodings and proposals recomputed for this request |

## Open questions

Which historical corpus records were actually sampled by every optimizer step? Which held/test families are provably absent from every inherited encoder checkpoint? Does a changed policy improve matched search under the same HWM identity? Which unsupported fitted heads merit export engineering? These questions need additional evidence and are not answered by interpolation or by multiplying checkpoint step counts.

## Publication verification

The renderer emits Markdown and PDF from the same numbered content and checks internal/local links. The separate verifier checks output hashes, page count, bookmarks and extracted page text, then creates contact sheets covering every page for visual inspection. The asset-inventory checker independently matches every accepted tensor name/shape and the total parameter count. Figure values come from retained data; no missing training segment is interpolated. Render and inspection receipts live with the publication evidence.
