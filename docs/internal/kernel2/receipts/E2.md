# Track E2 — expression operators v2

This serial prerequisite follows E0 admission and the existing E1 declarations.
E3's expression arms require these operators before Track E can qualify shipping
search and EEC creation/change/removal for B05. This slice adds no new scalar
function, evaluator identity, frozen fixture, or shipping profile selection.

The separate revision-2 kernel2 profiles declare seven expression arm weights.
Revision-1 canonical profile identities remain pinned and unchanged. New methods
live below the non-hashed `math_expr/evolution.rs`; its old implementation stays
byte-identical. Each method uses a separate RNG stream and reuses E0's manifest
membership and variable-leaf checks. Every accepted output is checked after
lossless source printing/reparsing against the recipient scope and profile caps.
Negative literals count both nodes. Columns are bounded below 8 and `x` is legal
only in a map scope.

The closure gate retains both revision-one profiles and checks both additive
revision-two profiles separately, keyed by id and revision. Their existing
counts remain `(a) 51`, `(c) 956412`, `(d) 233`, `(e) 153`; the manifest-wide
fault count remains 971397. Clause (b) still awaits the later shipping operators.

`grow_v2` uses ramped half-and-half over the profile pool, with node/depth budgets
and a required variable leaf. `mutate_v2` draws an arm before a site: point swaps,
subtree regrowth, hoist, shrink, relative Gaussian constant jitter, unary wrap,
and binary insertion. A rejected edit retains its selected arm and legal parent.
`crossover_v2` admits only recipient-compatible F64 subtrees of at most
`1 + 2 * replaced_nodes`, under the complete recipient budgets.

`optimize_constants_v2` receives training rows and targets only. The default
`LinearScaled` objective fits an intercept and slope by OLS, then minimizes MSE
while deterministically refining expression constants. Elementwise expressions
use a context-aware `Callback`. Both reject traced Domain/Hard faults before
scoring; an empty map is also refused. The declared elementwise scope controls
tracing and objective admission even when an expression has no `x` leaf. The
budget includes the initial candidate
and every attempted trial, including rejected trials. No fault is scored as zero.

Acceptance:

```sh
cargo test --locked -p feat-math --test kernel2_expression_search
```

Twenty-one nonignored tests cover 100,000 grown children, 100,000 children for each
of the seven arms, 100,000 size-fair crossovers, weighted arm frequencies, 1,000
bounded chained edits, seed replay, tiny scopes, revision-1 identities, callback
training inputs and budgets, and traced fault refusals. A tests-first regression
for independent review P2 (PR154, review5389263369) proves that `row_l2+0.5`
executes a nonempty map and refuses empty map rows before calling the objective;
map scope also refuses the row-only LinearScaled objective without an `x` leaf.
The synthetic OLS case
recovers `y = 3*sin(1.7*c0) + 0.5` within `1e-6`. These are local operator proofs;
E3 wrappers, E6 pipeline/CLI integration and EEC qualification remain later gates.
