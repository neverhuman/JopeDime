# Track E3 — profile-aware pipeline wrappers

This is the next serial prerequisite of Track E6 shipping expression search and
EEC clause (b), required before B05 generation. It adds the v3 wrapper API without
changing the legacy default. The jope-pipeline offspring path and CLI flags remain
the separate E6 gate; this receipt does not claim a qualified live learning loop.

Revision-3 kernel2 profiles add declared pipeline operators to revision 2.
Revision-1 and revision-2 canonical JSON identities remain unchanged. The shipped
wrapper API now exposes both revision-3 profiles through
`shipped_kernel2_profiles`; it consumes their stage/head pools, birth domains,
probabilities, mutation weights, expression pool, node/depth budgets and stage
caps. The baseline and experimental pools are unchanged. New functions return
typed errors for invalid profiles, input widths or parent programs.

`random_program(profile, input_width, seed)` creates an admitted canonical
pipeline. `mutate_program` draws among the six v2 stage arms and ExprGrow,
ExprEdit and ExprDrop before choosing a site. `crossover_programs` draws a
one-point stage crossover or ExprCross; its expression donor always comes from
the second parent's carriers. A missing donor returns an unchanged recipient,
never an expression fabricated from the recipient itself.

Expression creation, mutation and typed size-fair crossover use E2's operators.
Their scope is the lower width at the selected position, computed through
`pipeline::next_width` with E0's conservative one-row assumption. `x` is legal
only in map. Every returned program goes through E0's codec fixed point, scope,
manifest, variable-leaf and profile-budget checks. A rejected edit retains the
drawn arm and returns the admitted canonical parent with `changed=false`;
resampling a different arm would distort the declared proposal distribution.
Evaluation-budget accounting remains the later integration gate.

## Acceptance and remaining gates

```sh
cargo nextest run --locked -P pr -p feat-math \
  --test kernel2_pipeline_search --test kernel2_expression_search \
  --test kernel2_search --test kernel2_closure
```

Twenty-two new nonignored tests cover 100,000 births; 100,000 children for each
of nine mutation arms and two crossover arms across widths 1/3/8/20/600; profile
weights; seed replay; actual donor transfer; lower-width scope; caps; declared
parameter domains; missing sites; invalid parents, widths and distributions.
The width test uses AST scope checking and requires over 900/1,000 successful
insertions into a narrowed derive pipeline, so rejection alone cannot satisfy it.
The closure gate retains every old revision and pins revision 3 to the same
existing counts: (a) 51, (c) 956412, (d) 233, (e) 153; manifest-wide (c) 971397.
An explicit E3 fixture-identity successor chains from B02, without editing B02 or
the historical manifest. A shared test-only checker keeps every other fixture
strict; a negative regression rejects broken/missing chains, duplicate fixture
entries and attempted behavioral rebaselines.
Element-by-element EEC clause (b), complete C++ recipe closure, E4/E5 measurement
and refinement, and E6 runtime/CLI integration remain separate requirements.
