# Track E4/E5 — library measurement and refinement

This is workplan PR13, a serial hard prerequisite of E6 shipping expression search
and EEC clause (b), required before B05. It adds opt-in library APIs; legacy CLI,
search defaults, offspring, observation JSON and receipt v3 stay unchanged. It
does not qualify the missing shipping integration or a live learning loop.

`jope_pipeline::kernel2::Kernel2Evaluator` accepts revision-three baseline or
experimental profiles. The settled OQ4 default is RejectHard. Explicit Penalize
policies validate both lambdas and reuse WP1.5 FaultTotals arithmetic; Legacy is
refused by this API. E0 admission runs before fitting. Traced training and held-out
passes are pooled once; in-sample predictions do not double-count training cells.
Rectangular rows and fitted widths are checked before prediction. A scope, width
or Hard refusal is `inadmissible`, with no score. Completed training-stage fault
counts are retained if a later stage or head fails; no pass is replayed. Domain rates,
constant-output evidence and saturation rates accompany the underlying existing
Observation, whose legacy serialized shape is untouched. Penalized held-out R2
ranks candidates; optional fault ties use the existing anchored runs, avoiding a
non-transitive floating-point comparator.

`EvaluationBudget` is shared by ordinary measurements, every constant trial
(including rejected trials), and refined child measurements. Exhaustion starts
no measurement. `refine_training` takes only training rows and targets; its
whole-pipeline callback cannot access held-out data. Carrier prefixes are fitted
on those same training rows, with their actual widths and map/derive scope.
Every E2 trial rejects Hard/Domain faults and must pass full E0 admission. Stage
order, training objective and trial stream are deterministic. Initial failed
refinement attempts remain charged and reported. Malformed rows are refused before
any execution or charge; execution failures in a valid training prefix are contained
and charged through the same failed-initial-attempt path.

`finish_generation` is the library hook for E6: top-k scored constant-bearing
programs receive budgeted refinement, with a reserved evaluation for the resulting
child. Successful results are remeasured with origin `refine`, parent digest and
actual trial/refusal counts. Held-out data enters only that child measurement.
No scaling, fitting or constant selection uses held-out labels.
