## Behavior

The emitted PRELUDE's `fitted_index` checks the requested index against the actual row, mask, fill or guard vector before use. It covers `select_corr` values and mask, `impute`'s lazy zero-cell fill and indicators, both indices of `pair_prod`, `poly_interact` and `pair_ratio` plus the ratio guards, `corr_screen`, and `roll` on an empty row. A failed check raises `FittedWidthError`, which both row and table ABIs return as status 8; the unchanged host runtime reports model status 8 as error 108. Other status values retain their meanings. Valid index expressions and outputs are unchanged.

`row_mean` and `row_std` divide an empty row by one. Legacy predictor paths pad an empty stage row and mask to `[0.0]`; the V3 path keeps its nonpadding behavior. A `piecewise_linear` interval no wider than `1e-15` uses the runtime's step value, including tied edges, and a wider interval uses the signed width. `FITTED_CPP_REVISION` is 3 in the PRELUDE, codec and container. Decoding still accepts revisions 1–3 and checks source equality for revision 3 only; `load` regenerates older libraries from their embedded fitted model without refitting. The frozen host file `crates/feat-math/cpp/fitted_runtime.cpp` is unchanged. The Rust V3 `piecewise_linear` arm now reports a width error for fitted edges past a nonempty block where it previously panicked, while a block with no rows retains #132's no-width-comparison rule.

The prepared tests cover every listed invalid fitted stage, the table and legacy ABIs, empty-row reductions, empty legacy stage outputs, tied intervals and a real revision-2 container. The revision-2 container validates, then loads with a regenerated revision-3 library; predictions match the stored revision-2 library and Rust runtime bit for bit on valid input. The prepared `parity_bits` strict run had 0 unexpected and 0 stale allowlist entries, so no allowlist entry moved. The emitters lane now runs `advanced_v3_fitted_cpp` with AddressSanitizer and UndefinedBehaviorSanitizer and under g++ C++20; clang++ is outside the fitted compile rule, which requires g++ 13.3.
