# EurekaZero — north-star paper draft

*Learning to Innovate in a Single Proposal: EurekaZero* is the paper this program intends to earn.
It argues that inventing a solution is a move in a game — the problem is the state, the typed
candidate is the move, an independent verifier is the referee and the best known solution is the
opponent — and that a network trained on verified outcomes of search can make a strong first move
without searching. One interface covers three games with different output roles:

```text
game_state_encoding  ->  solution_embedding  ->  solution
(dataset | optimization history | engineering specification)  ->  (procedure | next query | CAD program)
```

**Status: north-star draft. Every EurekaZero result in it is synthetic.** The framing, formulation,
protocol, architecture, analysis plan and historical evidence are real. The results show the shape of
the finished paper so the team can see what it is building toward; none of the reported EurekaZero
experiments has been run. The draft cannot be submitted, and its own checks refuse to let it be.

## How synthetic content is kept honest

| Mechanism | What it does | Enforced by |
| --- | --- | --- |
| `\syn[EZ-Gnn]{value}` | every synthetic number is purple and hyperlinks to its gap-ledger entry | `scripts/check.sh` refuses any synthetic macro outside `\syn` and any unknown gap id |
| `\synfigtag` | every figure that plots synthetic data carries a SYNTHETIC tag | the check refuses a figure that reads `data/synthetic/` without it |
| SYNTHETIC banners | every synthetic CSV and `generated/numbers.tex` starts with a banner | the check refuses a missing banner |
| deterministic generator | `scripts/synthesize.sh` regenerates every synthetic file byte for byte (seed 20261023) | the check refuses hand-edited synthetic data |
| gap ledger | `northstar/gaps.json` names, per synthetic result, the work package and acceptance test that must replace it (Appendix K) | the check refuses an unledgered or uncited gap |
| claims ledger | `evidence/claims.json` states every claim, its minimum evidence and status (Appendix M) | schema and status vocabulary checked |
| page footer and watermark | every page says the purple results are synthetic | the PDF check refuses a page without the footer |
| submission guard | `make submission-check` fails while any synthetic element remains | by design, this draft fails it |

Real historical results (Appendix I) carry EST and PRE badges and are taken from the repository's
records, including the unfavourable ones.

## Build

```sh
make -C docs/paper/eurekazero check        # sources, ledgers, vocabulary, synthetic labelling; no TeX
make -C docs/paper/eurekazero self-test    # breaks a disposable copy ten ways; every refusal must fire
make -C docs/paper/eurekazero pdf          # checks, typesets, then checks the PDF
make -C docs/paper/eurekazero synthetic    # regenerates data/synthetic/ and generated/numbers.tex
make -C docs/paper/eurekazero submission-check   # expected to FAIL on this draft
```

Output: `target/eurekazero-paper/EurekaZero-NorthStar.pdf` (with its TeX log and build
environment). The build is bash throughout (ADR-0006) and needs XeLaTeX, latexmk and BibTeX (TeX Live
2023 or later), Poppler, jq, curl, unzip and sha256sum. Fonts come from `fonts.lock`, the same pinned,
SHA-256-checked archives as the InnovationZero paper, cached outside the working tree.

## Layout

- `main.tex`, `ez.sty` — the manuscript and its style, including the synthetic-labelling machinery.
- `sections/00-abstract.tex` … `13-conclusion.tex`; `appendices/A-formal-definitions.tex` …
  `M-claims.tex` — one file per section.
- `figures/` — TikZ and pgfplots sources. Conceptual diagrams (`fig-game`, `fig-network`,
  `fig-protocol`, `fig-loop`) contain no data; every other figure reads `data/synthetic/`.
- `data/synthetic/`, `generated/numbers.tex` — synthetic north-star data, generated by
  `scripts/synthesize.awk`.
- `northstar/gaps.json` — the gap ledger; `evidence/claims.json` — the claims ledger;
  `evidence/literature.md` — the verification record for external facts.
- [`RESEARCH_VISION.md`](RESEARCH_VISION.md) — the north star, the work packages and how agents
  replace each synthetic result with a measurement.
- [`EDITORIAL_DECISIONS.md`](EDITORIAL_DECISIONS.md) — naming, the protected boundary, what the
  draft claims and does not claim, and why.

## Relation to InnovationZero

[`docs/paper/innovationzero/`](../innovationzero/) remains the record of what the program has
published and measured. EurekaZero generalizes its question — can a learned proposer commit a good
candidate before testing anything? — from learning procedures to any problem that can be set up as an
innovation game. Historical InnovationZero claim identifiers are unchanged.
