\section{The identical-cuts pilot: protocol and per-dataset results}
\label{app:pilot}

\paragraph{Protocol} \code{jope-bench run} at repository commit \code{8d0fa7b} (unchanged for every
file it reads at \code{bdf9441}), over \code{datasets/test}: fold seed 20260907, five folds, screen fold
0, every method deep-scored on all five cuts (\code{--top 20}); the engine's proposer with 32 candidates
in each of 8 rounds, re-run on every cut's training rows (\code{--search --search-pop 32
--search-gens 8 --resample-search}); entrants \code{--entrant Opus5p5\_Extra}, \code{--automl
gpt6-astra-max} and \code{--native GPT6p1\_Sol\_Max}; external adapters for scikit-learn 1.7.2,
XGBoost 2.1.4, LightGBM 4.6.0 and CatBoost 1.2.10 at library defaults with one thread. Ladder by
\code{jope-bench ladder} and Elo by \code{jope-arena elo}. Host: a 2-vCPU cloud container with 7 GB of
memory, \code{rustc} 1.97.0 (the pinned 1.97.1 was not available), two workers; total wall time 388 s.
The score table is committed as \code{evidence/pilot-2026-10-22/scores-deep.csv} (SHA-256
\code{86fec7790c8f\ldots}) with the Elo output beside it; the engine found byte-identical programs to
the committed same-cut run on all ten datasets.

\paragraph{Per-dataset error} \Cref{tab:rel} gives each method's pooled out-of-fold RMSE divided by
the best of all eighteen methods on that dataset. Two rows deserve attention. On \code{693890aa}, a
single-feature dataset whose best method is a Gaussian process baseline, most methods' errors are
several times the best, and this one dataset moves every geometric mean in \cref{sec:pilot}. On
\code{21fbfe8b} the engine's Gaussian-process program has twice the best error: the program chosen on
the screen cut generalized poorly to the other cuts.
