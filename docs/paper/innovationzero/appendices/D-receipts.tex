\paragraph{Method for \cref{tab:yield}} Source tokens are frozen bytes divided by 3.5 (range 3.0--4.0
characters per token). For a lexical comparison on a common counter, the repository's source-count
receipt gives 14,706 tokens for Opus, 5,924 for Astra, 5,442 for Sol and 17,417 for Gemini
(\code{assets/automl-elo/v1/SOURCE\_COUNTS.json} in pull request \#407). Ranges combine the session's
own token range with the character range, taking the least and most favourable pairing.
