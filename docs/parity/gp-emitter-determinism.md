# Scalar GP emitter determinism and differential compilation

The gate exercises the public typed scalar GP recipe route. This preserves nonfinite literal IEEE bits through `ScalarExpressionProgram` rather than converting NaN or infinities into text that the historical parser refuses. It reuses the existing Python, Rust and C++17 emitters and both numerical policies. It does not add a grammar or alter grammar-coverage files.

The fixed corpus has 82 trees: 46 adversarial cases, 32 random trees and four constant Min/Max signed-zero regressions from PCG32 seed `0x4750454d4954`, stream 54. It includes all 23 versioned functions, all five binary operators, all seven row reductions, both carriers, depth 16, NaN payloads, both infinities, signed zero, the smallest subnormal, and huge/tiny constants. Thirty probe rows include protected division threshold neighbors and log/sqrt domain inputs. Every case fits the same 16-row training table and labels.

`repeated_emission` checks exact bytes for two emissions in its own process and two emissions in each of two fresh processes, per language and case. The child is an explicitly named ignored subprocess entry point, invoked twice by the parent; it is not skipped coverage of the corpus. Timing measurements are not emitted program bytes and are outside this comparison.

Eight compile shards compile each original artifact separately. Rust appends one test driver and invokes `rustc --test --edition=2021 -C opt-level=1`; this preserves the generated CLI function and avoids renaming it. Python runs `python3 -m py_compile` and imports the original file from a separate driver. C++ includes the original file from a driver and invokes `g++ -std=c++17 -Wall -Werror -O1 -ffp-contract=off -fno-fast-math`. No emitted text is removed or rewritten by a harness. Compiler absence or any failed compile/run fails the gate.

The reference is native `ScalarModel::transform` plus `predict`, not another emitter. Features are compared before the ridge prediction clamp, so a common saturated prediction cannot hide a feature error. Fault flags and output counts compare exactly. Finite nonzero outputs use the fixed rule `abs(actual-reference) <= 1e-12 + 1e-12 * max(abs(actual), abs(reference))`; either zero requires identical IEEE bits. Nonfinite outputs must have the same class and infinity sign. This is a same-host PlatformLibm comparison, not portable bit parity. Existing parity tolerances and allowlists are untouched. A retained comparator control rejects a signed-zero mismatch, NaN/finite mismatch, opposite infinities and a material finite difference.

Artifacts and native bit references remain under the printed `target/tmp/gp-emitter-determinism/` directory. It is retained after the test, including failures. Each case also retains its exact program binary. The initial source failure and command evidence is under `/home/ubuntu/jope-evidence/kernel2/gp-emitter-determinism/initial-01/first-compile/`: C++ failed on misleading scalar-label-validation indentation and unused generic sanitization/epilogue helpers. The fix braces the same checks and omits the two unused helpers only for a one-stage scalar plan. StableV2 recipes also include independent asinh/reduction entrypoints that can be unused; those two functions carry `[[maybe_unused]]`, without changing their bodies or suppressing other diagnostics. Seeded case 58 exposed an LLVM-folded Rust `+0.0.min(-0.0)` result that differed from native runtime `-0.0`. Scalar-v2 Rust Min/Max now explicitly select the second operand on ties, matching the observed native runtime kernel. The historical emitters are unchanged. Four constant Min/Max trees retain both signed-zero operand orders. The failing native/source/output files are retained outside the checkout under the same evidence root.

Acceptance: `cargo test --locked -p feat-math --test gp_emitter_determinism -- --nocapture`. All ten normal tests must pass; the child entrypoint is invoked twice by the parent. A successful run compiles and executes 246 artifacts, compares 246 exact fault vectors, and verifies 1,476 emissions across three processes. Coverage is bounded to the 82-tree corpus and this toolchain/platform, not all possible GP programs or a portable-libm claim.
