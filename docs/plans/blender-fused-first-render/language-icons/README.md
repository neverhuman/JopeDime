# Language icons

These transparent 192 × 192 PNGs identify the emitted language or binding on screen. The marks belong to their respective owners. Their use identifies the language.

Five SVGs come from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/54cfe13ac10eaa1ef817a343ab0a9437eb3c2e08). The upstream MIT notice is included in [LICENSE-devicon.txt](LICENSE-devicon.txt). Each SVG was rasterized, cropped to its alpha bounds and centered on a transparent square.

The [official Rust white-outline logo](https://raw.githubusercontent.com/rust-lang/rust-artwork/7b54b6689dc310db2f301d7bcda847f016bd447c/logo/rust-logo-white-outline.svg) is credited to the Rust project. See its [artwork notice](https://github.com/rust-lang/rust-artwork/blob/7b54b6689dc310db2f301d7bcda847f016bd447c/logo/README.md) and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The supplied color and geometry were preserved during rasterization and centering.

The C badge uses the [community hexagonal C mark by ElodinKaldwin](https://commons.wikimedia.org/wiki/File:C_Programming_Language.svg), which Wikimedia Commons lists as public domain. Its SVG was rasterized and centered on a transparent square.

The Dendrite cut uses the [CUDA Toolkit artwork](https://developer.download.nvidia.com/images/cuda-kv-toolkit-ari.jpg) from the [NVIDIA Developer CUDA page](https://developer.nvidia.com/cuda) as a local `--cuda-icon` input. The JPEG SHA-256 for this cut is `094695167b0dec11077e35c007bfdb2229984d5da82247bfbe33d7dceaefc482`. The repository's fallback [CUDA type badge](cuda.svg) is original JAIN film artwork.
