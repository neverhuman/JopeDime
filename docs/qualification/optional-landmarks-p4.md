# Optional landmark product consumers: P4 implementation

This bounded continuation implements the product integration against immutable Dope
`25d1785c823e0a401b8775306666924e407ccd9f`. It does not close preparation, trained-model quality,
live flywheel, final package or latency qualification. P1/P2 owners retain the Dope repairs on
[Dope #340](https://github.com/neverhuman/dope/pull/340); Jope changes remain in the existing
optional-landmarks lane. No deployment, training campaign, governed distribution or promotion
is part of this phase.

## Resulting behavior

`--landmark-consumer direct` emits actual raw Dope512. `--landmark-consumer jope-dl` feeds those
same coordinates plus authenticated supplied foundation1024/target512 through the existing
Jope context MLP. Omitted consumer selection preserves the existing landmark path. Both choices
propagate through `jope encode`, pipeline commands and appliance `fit`/`fit-predict`. Existing
final stdout and frozen pipeline receipt v3 remain intact; companions and events identify the
chosen output. Raw Dope512 and derived `JopeContext512` are different opaque products. The
latter bridges directly to the current Rust CPU decoder and has no fusion method. Context/Dope
CUDA execution shares one owned device; the scalar decoder/reward surface remains CPU-only.

The component request supplies references only. The separately configured controller store
provides adopted policy and a controller-owned authority snapshot. The shared production
admission verifier moved to `jope-records`; the existing learning API remains a thin State
adapter with unchanged wire labels. A new opaque FIT admission requires every ancestor to be
train_search, training view, train/train_fit, episode-bound and train-only prior exposure.
All metadata is checked before subject/target payloads. Known prohibited model payloads are
refused before opening, independently of data-use admission. FIT scope binds physical ordered
row IDs, prepared source, task, fold and immutable preparation source. Component recipe,
producer ancestry, finite LE-f32 bytes and widths are verified. Sampling/masks can rebind the
same static component values only within that exact FIT scope.

Admission is checked on use, after the MLP, before publication, before/after event callbacks
and after worker join. This includes none/fast sessions whose worker has already completed.
Controller changes, time expiry, CAS corruption and revocations produce a failed outcome with
the last valid output. Duplicate conditioning does not bypass admission. Static preparation,
resident component tensors and the learned result cache survive progressive updates; model
weights are not reloaded per update.

The controller-snapshot helper produces a read-only review artifact from existing State. It
does not install authority, adopt policy, sign evidence or repair an interrupted ledger. It
uses descriptor-relative nofollow reads, bounds and the existing append lock; corrupt/stale
HEAD, symlink ancestors, oversized inputs and concurrent changes fail closed. The runtime
requires a separately installed snapshot; there is no candidate-controlled installer.

The selected policy projection is an opaque immutable capability. It verifies the pinned
original parent manifest, four selected files, complete tensor/config/registry metadata and
one required notice. Only this closure is opened. The full bundle loader remains strict.
The [asset review packet](optional-landmarks-policy-assets.md) specifies six entries totaling
117,524,724 raw bytes, original hashes, licences, conditional notice and draft SBOM records.
Executed Rust verification confirms projection digest
`eeae7b5b7e35f4976db4bd0b424685eb6e5d4a42152e16c92d7d6b088485217c`.
This proves content identity, not permission to distribute a governed release bundle.

Output protections cover exact input paths/inodes, policy/controller subtrees and not-yet-created
output directories. Companion files are create-only; appliance writes remain atomic. The
appliance model-object root is checked as well as explicit model/prediction outputs. No input
tree is scanned to infer authority or licensing from arbitrary external hardlinks.

## Verification and remaining acceptance

The machine-readable [P4 verification record](optional-landmarks-p4.json) contains the final
focused commands, log hashes, counts and CUDA outcome. All test component vectors are explicitly
synthetic execution fixtures. They are not measured foundation/target features, model quality,
new issuer credentials or production controller grants. Explicit selected-asset tests fail if
local governed assets are absent; older full-bundle test paths are excluded from those runs.

The initial selected-asset CPU run executed 15 tests with no failures, including regression,
binary and K=3 multiclass native progressive/full equality, a frozen PyTorch context oracle,
actual MLP arithmetic, no-double-MLP and two authority-change lifecycle cases. Historical
learning admission/snapshot tests and newly scoped refusal/size/symlink tests are part of the
focused final matrix. Initial compile/lockfile failures are retained under lane target evidence;
no failed preflight is reported as a passed test.

Final focused checks pass: Starforge library 71 nominal passes (four historical artifact-guarded
skips), 15 explicitly executed selected-asset integration tests, eight shared admission tests,
six doctests, five controller snapshot tests, 26 historical admission/snapshot regressions,
62 runtime tests, six schema tests, two pipeline lifecycle/resource tests, four CLI/product
checks, three appliance/product checks and three native compatibility checks. Overlapping
ordinary and selected-asset suites are not summed. The old candidate/full-bundle artifact paths
were not requalified by this phase.

The explicit reserved RTX3090 test also passes on all three tasks: 21 context comparisons have
maximum absolute error 7.390975952e-6 against the CPU oracle (tolerance3e-5), exact terminal
progressive/full equality and resident raw/fusion/learned tensors. The12.46-second reservation
is test wall time, not a latency benchmark. Seven-package CUDA all-target Clippy, dependency
advisory/bans/licence/source checks, one-Candle/source identity, model manifests, formatting,
document links and repository layout pass. The GPU is released. Final aggregate `just required`
was deliberately not run on this interim preparation/weight pair.
