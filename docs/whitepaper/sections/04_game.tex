% ----------------------------------------------------------------------------
\subsection{Why games came first}\label{sub:game-games}

Games became AI's laboratory because they supply four things at once: fixed
rules, an impartial referee, a clear winner and cheap replay. Chess was chosen
because it is ``sharply defined both in allowed operations (the moves) and in
the ultimate goal (checkmate)'' \citep{shannon1950chess}, and checkers showed
that a program could improve by playing itself \citep{samuel1959checkers}.

These four properties support reproducible repeated evaluation. People
scale judgment similarly (\cref{sec:road}), through prizes, leaderboards and
the common task framework's ``scoring referee'' \citep{donoho2017fifty}.
Once problem and solution are specified, invention shares the first three
within the limits of \cref{sub:game-played}; cheap replay depends on
evaluation cost (\cref{sec:price}).

\subsection{The rules}\label{sub:game-rules}

Every submitted program counts as an attempt, including an illegal move.
The reference writer $\writer$ reads the encoded problem; the referee uses
the incumbent as a separate standard (\cref{sub:method-board}). The incumbent's code and
score \mbox{must stay outside} the writer's input.

The top band of \cref{fig:game-loop} follows the single-candidate contract
in \cref{box:searchone}; the dashed box covers reference training.

Formally, the game is a tuple of six parts,
\[
  \Game = (\Prob, \encP, \Sol, \referee, \reward, \opp).
\]
In the reference design, $\encP$ represents a problem $p \in \Prob$ as
$z_p$. The referee $\referee$ reports validity and score, the
%
%
reward $\reward$ orders moves, and the opponent $\opp$ supplies the
incumbent $\inc{p}$. The tuple extends Rice's model of algorithm
selection \citep{rice1976algorithm}: the player writes an algorithm instead of
\mbox{picking} it, and the incumbent sets the comparison standard.

One move makes the game a contextual bandit: board as context, program as
action and verdict as reward \citep{lattimore2020bandit}. Verified programs
can displace the incumbent, changing the comparison standard. Move cost
sets the games apart: Go offers about 250 legal moves per turn over about
150 turns, each free to check \citep{silver2016mastering}; this game offers
one move, costly to judge. Under a single-candidate budget, the chance $\winprob$ of a win matters
directly (\cref{eq:taste}). Whether training raises that win probability on unseen
problem families is the empirical test in \cref{sec:results}.

\subsection{The board and the move}\label{sub:game-board}

The board is the aim pillar of \cref{sec:anatomy}, made machine-readable: a
summary of the training data, the objective and metric, and the constraints.
Landmark scores from cheap learners \citep{pfahringer2000landmarking} and
learned tabular summaries are possible encodings; \cref{sub:method-board}
specifies the reference encoder and its cost limit.
In the reference implementation, that encoder consumes prepared numeric training
rows and targets; the writer's engine and regression-task tokens are
supplied separately. The objective, metric and budget are protocol
settings, not \mbox{additional input fields} in this encoder call.

Board quality requires tests: it should preserve distinctions relevant to
algorithm choice, ignore irrelevant reorderings, exclude final evaluation
information and have a measured cost. Naming an encoder establishes none
of these properties. People still choose the problem and define what
counts as useful.

A move is one complete program written in a typed language over learning primitives.
A task-specific grammar restricts legal moves, and \cref{sub:method-move}
specifies the reference operator vocabulary and composition limits.

Types remove whole classes of stillborn
programs before they run \citep{montana1995stgp}. Canonicalization can merge
syntactic variants; it need not identify every functionally equivalent
implementation. AutoML-Zero
reused scores when hashes of truncated predictions matched after a short
training and validation probe \citep{real2020automlzero}. Matching a probe
does not establish \mbox{agreement on other} inputs (\cref{sub:method-move}).

The language bounds what can be expressed; changing its primitives changes
that space \citep{boden1990creative}. Structural constraints can prevent invalid programs; their effect on useful \mbox{proposal
quality} must be measured (\cref{sec:results}).

\subsection{The referee and the opponent}\label{sub:game-referee}

The reward is an ordering first and a number second. Validity is a gate: any
stillborn program scores below any valid one. Past the gate, programs rank by
improvement over the incumbent on hidden folds. The reference promotion
rule keeps the existing incumbent on a tie. Novelty never pays for losing: any novelty
bonus (\cref{sec:price}) must respect the order. For a stillborn program
$\tilde{w}$, an also-ran $w^-$ and a win $w^+$ on board $p$,
\[
  \reward(p, \tilde{w}) \;<\; \reward(p, w^-) \;<\; \reward(p, w^+).
\]

The opponent is a ratcheting incumbent: replacing it requires strict
improvement under the same evaluation protocol. The reference design
proposes a separate admission test for a retrained writer
(\cref{sub:method-selfplay}). Its two self-play rules compare against
incumbents retained from earlier play. AlphaGo Zero likewise
separated network admission from move selection \citep{silver2017mastering}.
These are reference rules, not a record of writer improvement. The later loop in
\cref{sec:method-status} updates only a cost-ranking adapter; its default
admission gate can retain equal utility. That record does not establish
retraining or admission of the neural writer.

Subtracting the incumbent's score does not change which move is best.
Promotion raises the bar, turns old winners
into today's also-rans and shifts which problems are worth playing. The
reference targets use each program's rank within its scored list, with no
novelty term (\cref{sub:method-map,sub:method-selfplay}).

\subsection{One game, many boards}\label{sub:game-boards}

Casting algorithm discovery as a game is not new, but earlier games wrote one
family of problems into their rules, as AlphaTensor did for matrix
multiplication and AlphaDev for sorting
\citep{fawzi2022alphatensor,mankowitz2023alphadev}. AlphaZero used one algorithm
for three games and trained a separate network for each
\citep{silver2018general}. Here the problem is an input on the board, so one
player can, \mbox{in principle, learn} many boards.

The historical reference checkpoint and comparison protocol cover only
tabular regression. Binary and multiclass classification, ranking,
forecasting and relational prediction remain prospective; each needs a
qualified encoding, program language, metric and validation protocol.

Beyond machine learning, examples of referees include sorting tests
\citep{mankowitz2023alphadev}, evaluators for mathematical constructions
\citep{romeraparedes2024funsearch} and accelerator-kernel timers
\citep{novikov2025alphaevolve}. These motivate extensions of the recipe,
rather than results of this paper (\cref{sec:meaning}).

\begin{keyidea}
A reliable referee makes a discipline a candidate for this game; transfer
to that discipline still needs evidence.
\end{keyidea}

\subsection{The analogy's limits}\label{sub:game-played}

Four limits qualify the analogy to board games.
\textbf{The referee is noisy:} picking a
winner by a noisy validation score biases that score upward
\citep{cawley2010overfitting}. Strict numerical improvement alone does not
quantify confidence; independent evaluation and an uncertainty protocol are
needed to interpret it.
\textbf{Attempts consume budget:} fitting, validation and failed execution
all incur costs; invalid programs may stop before fitting
(\cref{sec:price}).
\textbf{The referee can be gamed:} the evaluation harness must resist exploits
\citep{metr2025rewardhacking}. \Cref{sub:method-referee} specifies the
isolation and parity checks required here.
\textbf{No algorithm wins everywhere:} averaged
uniformly over all problems, no learner has lower error off the training set
than another, ours included \citep{wolpert1996nfl}.

Problem structure motivates a player that chooses its bias from the board.
\Cref{sec:results} reserves tests of that hypothesis against fixed
frontier-designed regressors, with paired outcomes beside Elo summaries
\citep{elo1978rating}. Non-transitivity limits what a single rating can establish
\citep{balduzzi2018reevaluating}. A worked game, chosen by a rule fixed
before inspection, will \mbox{accompany the results}
(\cref{sub:results-failures}).

\Cref{sec:price} accounts for the full cost of an invention attempt,
including invalid programs and valid losses.
