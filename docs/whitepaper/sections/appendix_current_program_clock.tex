\section{A Current Program-Incumbent Event Clock}\label{app:current-program-clock}

\Cref{fig:fw-current-program-clock} uses a separate capture of the latest
20 consecutive completed summaries, with every program-event count checked
against the promotion journal. The full-round clock includes all work and
waits, including rounds with no event. These records retain the adaptive
training-side scope and unresolved source-binding requirements of
\cref{sec:method-status}; independent first-proposal outcomes remain pending.
