  \centering

  \caption{\textbf{Rounds grouped by training-program incumbent events.}
  Every bar contains 20 completed-round summaries. Colored segments count
  rounds with 0, 1, 2 or 3+ strict training-program incumbent events;
  parentheses report total events in each window. These descriptive counts
  are not a matched comparison or evidence of independent first-proposal
  improvement.}

\Cref{fig:fw-event-distribution} summarizes the training-program counts
underlying \cref{fig:fw-recent-development,fig:fw-followup-development,fig:fw-later-development}.
Each window stays separate; the records say nothing about the gaps between
them. These are incumbent events within training contexts, not independent
discoveries or a measure of the writer's first proposal.
