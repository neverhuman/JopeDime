A read-only snapshot taken on November 1, 2026 retains 20 consecutive
completed rounds, 2508--2527. \Cref{fig:fw-subsequent-window} pairs 15
journaled strict training-program incumbent events with candidate adapter
scores from those same summaries. The recorded best remains 1.1378,
attributed to round 882; no adapter admission is recorded. This is a
separate window: unobserved rounds between windows are not joined.
