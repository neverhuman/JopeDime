# jope (Python)

Encoders, the policy transformer trainer, self-play services and research drivers of JopeDime. See ../docs/architecture.md.

Target-maker executable artifacts require SHA-256 pins before joblib deserialization.
Classical fit reports record `model_sha256` beside `model_path`. Fused bundle producers
record `artifact_sha256`, a mapping from each vectorizer, classical-model and optional
meta-scorer artifact path to its complete lowercase SHA-256 digest. Consumers reject
missing, malformed or mismatched pins with an error identifying the artifact. They
load the verified byte snapshot instead of reopening its path. Existing fused bundles
without this mapping must be regenerated by their trusted producer before loading;
the consumer never derives a missing expected pin from the file it is about to load.
Benchmark panel replay likewise requires its caller's complete digest and snapshots
mutable byte buffers before verification and pickle loading.

These checks detect corruption and replacement relative to the supplied pin. The
producer, caller and manifest remain trusted inputs: a matching digest does not
authenticate the producer or make arbitrary pickle/joblib artifacts safe to execute.
Neural checkpoint loading is outside this five-path fix.
