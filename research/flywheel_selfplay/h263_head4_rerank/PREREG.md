## Head loss definition, fixed before scores

Native full-pool r882 scores freeze a stable ascending top4 for each TRAIN context once before all smoke/training. Ties preserve pool index. IDs for all contexts may be frozen, but only current FIT contexts' labels enter gradients; SELECT/ASSESS/DL-Val never enter any training target. For each sampled FIT context, score its full native pool with the current adapter and the native first-four support conditioning. Gather its frozen four scores. Enumerate all six unordered pairs. True valid cost is raw fitness; invalid utility=-2, cost sentinel2. Drop any pair with absolute sentinel-aware cost gap<1e-4 and all invalid/invalid pairs. For valid/invalid pairs, invalid ranks worst even if a valid raw cost exceeds2. Thus invalid status determines ordering, and sentinel cost determines near-tie exclusion. Other pairs follow raw valid cost order. Loss=softplus(sign(cost_i-cost_j)*(prediction_j-prediction_i)), using validity override for sign. Mean over retained pairs per context, differentiable zero if none; mean over eight sampled contexts, including zero-pair contexts, times.5. Targets use saved float64 raw cost. No temperature or gap weighting.

Control backward, then eight full-pool head backward passes one at a time, then anchor backward, one global clip, one AdamW step, then optional retraction. This avoids changing CONTROL batches and bounds memory. Full-pool head forwards preserve candidate closure rather than replacing support with the four target labels. Anchor outputs cached from frozen r882; native/cached adapter forward must match bit-for-bit before training.
