CTXNORM_SHUF is a within-family label placebo. CONTROL is r882. No neural optimizer updates, new support reveals, GPU use or live-worker changes.

## Labels and features
Within each TRAIN context's r882 top4, valid finite costs alone determine median and MAD. Denominator is max(1.4826*MAD, .001). Relevance z=(median-cost)/denominator clipped to [-2,2]. Invalid/nonfinite slots have z=-2. Cutpoints [-1,-.25,.25,1] map to grades 0..4, with exact equality assigned to the upper grade. No valid candidates means four grade0 labels; tied valid costs get grade2. This valid-only definition and right-closed boundary choice are fixed before outcomes. LightGBM default exponential label gains remain unchanged: this intervention changes the relevance package (including available grades), not solely a loss scale.

r882 cached costs and all H265 features are frozen and hash-pinned. The cached r882 scores retain native support conditioning. The reranker consumes no additional test-time outcome reveals; this is not an unconditioned or literally zero-support end-to-end baseline. Full-pool features are preexisting non-outcome descriptors. Training labels and evaluation utilities are stored separately from input features.
