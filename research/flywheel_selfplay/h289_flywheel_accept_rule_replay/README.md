## Chronological replay
Each rule/seed starts at r3175 and considers all qualified later recorded candidates in chronological order. An accepted candidate becomes that replay's comparison incumbent. Future candidate records remain those produced by the actual writer; replay does not simulate altered optimization or GP generation.
- **R0**: context mean improves over that replay's incumbent. Apply the owner tie exclusion: gain must exceed 1e-4. Separately check literal recorded `mean>best` against the journal so this tolerance is visible.
- **R1**: compute the mean paired utility gain within each family, then the median across families. Accept only if that observed paired-family median is **>0.002** and the seed's bootstrap median-of-family-gains LCB95 is **>0**.
- **R2**: clip each context utility below at **-1.0**, then apply R1 to the clipped paired gains.
- **R3**: take raw family-mean utilities and convert them to empirical midrank percentiles within each family using **only r3175 and previously observed candidate rounds**, including previously rejected ones. For a value v, score=(count(history<v-1e-4)+0.5*count(abs(history-v)<=1e-4))/history length. Compare candidate and incumbent under the same past-only reference. Apply R1 to paired rank gains (strict .002 in percentile units), and additionally require raw paired-family median gain >1e-4 to prevent rank normalization accepting a raw tie. Add the current candidate to rank history only after its decision.
No ties within ±1e-4 are accepted; no tuning of margins, clipping, reference window, rank transform or seed after outcomes. A candidate failing the observed strict margin needs no bootstrap to reject; every bootstrap gate that is evaluated uses all 10000 draws.

For each accepted round, report raw utility gain versus r3175, all three seed CIs/medians, the rule-specific acceptance evidence, invalid/changed selections, and Elo. A recommendation witness may be accepted by any alternative rule/seed, but must have median raw bootstrap context-mean gain >=0 and raw LCB95 >-0.002 on **all 3 seeds**; report how many seeds accepted it rather than hiding seed sensitivity. The accepted-round union is fixed by these replays, not chosen by later gains.
