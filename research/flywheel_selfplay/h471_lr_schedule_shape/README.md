# H471: integrated-lr-matched 16-step warmup+cosine schedules (one-cycle, SGDR-2) on the gated pairnf step (offline, adapter-only)

**Status: `RUNNING` (pre-registration record).** This README records the design, code hash, probe, smoke and launch before any CV result exists. The verdict, metrics and red-team will be added once all 3 seeds write `summary.json`.

## Hypothesis
H466–H470 were all `NO_LIFT`. None of gradient-noise reduction (acc2/acc4), injection (gn05/gn10), Lookahead, objective shape or robust losses beat the `pairnf_z40` control. H470 showed that the noise only *drops* control changes, and the dropped ones are net positive. Across H452–H470 the only non-control arm that beat the control on any seed (paired family-bootstrap CI > 0) was H463 `s32cos_z40`: 32 steps, 2-step warmup and cosine decay to 0 at peak 3e-4. Its integrated learning rate (Σ lr_t ≈ 4.8e-3) equals the control's 16 × 3e-4, and its kept changes were a superset of the control's. That edge could come from the warmup + cosine **shape** (large early steps along the consistent direction, then a small-step settle that sharpens z-margins) or from the 16 extra gradient evaluations. H471 isolates the shape at the control's compute: **16 steps, the same Σ lr_t = 4.8e-3**, every arm on the control's random streams (`rng_arm = pairnf`, so init perturbation, batches and dropout are identical), z ≥ 0.40 gate unchanged:
- `pairnf_z40`: the control (H452–H470 pairnf + z ≥ 0.40, constant lr 3e-4 × 16). Adapter shas must equal the H470 `pairnf_z40` cells.
- `oc16_z40`: one-cycle, 2-step linear warmup then cosine to 0 over 16 steps, peak 6e-4. The lr per step (×1e-4) is 3.0, 5.94, 5.77, 5.49, 5.12, 4.67, 4.15, 3.59, 3.0, 2.42, 1.85, 1.33, 0.88, 0.51, 0.23, 0.06, which sums to 4.8e-3.
- `sgdr2_z40`: SGDR with two 8-step cosine cycles (warm restart at step 8, 1-step warmup each), peak 16/3 × 1e-4 = 5.33e-4. The lr per step (×1e-4) is 5.33, 5.13, 4.55, 3.69, 2.67, 1.65, 0.78, 0.20, repeated, which sums to 4.8e-3.

Not repeated (already falsified on this instrument): Polyak/EMA tail and ASAM (H457), 32-step dose and fbal (H461), recalibrated gate and the 32-step cosine (H463), ctxnorm, tail clip and pair weight 2 (H466), acc2, Lookahead and BT label smoothing (H467), acc4 and displacement-matched Lookahead (H468), trim10/trim25/Cauchy (H469), gradient noise (H470). Weight decay is inert at this horizon: AdamW decay is lr × wd × θ ≈ 3e-8 θ per step over 16 steps, so it is not tested.

## Pre-registered rules (unchanged from H452–H470)
- **Primary metric:** median across 3 seeds of pooled OOF Elo vs the incumbent, with 95% family-bootstrap CIs (families resampled with all their rows in both partition copies). **Non-floor Elo** is co-primary and drives selection. Elo only, no AUC.
- **Selection:** per seed, the max mean non-floor OOF Elo over the two partitions (ties broken by pooled gain).
- **Strict:** pooled OOF gain > 0.002 and gain CI low > 0; pooled Elo > 0 and Elo CI low > 0; non-floor Elo CI low > 0; Elo > 0 on each partition. Ties never win, and a tie with the control is not accepted.
- An arm counts only if it also beats the control in the paired family bootstrap (arm − control CI low > 0).
- **LIFT** requires a non-control arm that passes strict and beats the control on every seed, val91 not_worse on every seed, a clean red-team, **and** a median val91 gain beyond its cross-seed family-bootstrap CI (CI low > 0, the H470 closeout rule). Otherwise the verdict is `NO_LIFT`.

## Pre-registered red-team checks
- **Floor-recovery confound:** pooled gain from recovering −2.0 gate-fail contexts is not lift. Report non-floor gain/Elo, `recovered_gatefails` and `new_gatefails` per arm and seed.
- **Displacement / z-inflation confound:** both arms have the control's Σ lr_t, but per-step sizes differ, so z-margins can shift. Report kept counts and the median |z| of changed picks vs the control. An arm that keeps < 0.5× or > 2× the control's changes is flagged as gate-starved or z-inflated (cf. H461 s32: ~7× z-inflation, win rate 47%). Report kept-set overlap with the control (subset / superset / disjoint extras) and the non-floor win rate of the extras.
- **Schedule check:** the lr sequences above come from the harness formula evaluated offline (Σ lr_t = 4.8e-3 for both arms, matching the control's 16 × 3e-4). The probe uses 1-step folds, so it exercises only the code path, not the schedule. The smoke runs the real 16 steps.
- **Tie acceptance:** ties never win. Report W/T/L everywhere, and treat a val91 gain ≈ 0 with ≥ 85/91 ties as not evidence.
- **Equal-Elo coincidences:** equal pooled Elos with equal W − L are reported as arithmetic coincidences after checking that the adapters and decisions differ.
- **No label leakage:** the schedules are label-free. Held-out folds are scored by the label-free z-gate, and val91 is read once per seed for the selected arm only.
